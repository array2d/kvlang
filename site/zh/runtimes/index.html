运行时扩展

kvlang 是以扩展为主的编程语言。核心刻意保持最小，能力由 runtime 扩展与 lib 提供。多个 runtime 扩展运行在同一个 kvspace 中——同一棵树里的代码、帧与值，对所有参与者可见。

runtime 把 opcode 注册到 /lib/<opcode>；lib 是一组 rwir/rwfunc 定义，layout 进同一棵树。

Runtime Lib（依赖本行 runtime） 介绍 / 备注
runtime-c — 最小核心：取指、解码、执行、控制流与 native 派发。扩展 runtime 嵌入这个核心，而不是另起一套。
runtime-rs stdlib 第一个 runtime 扩展，也是它对应的第一个 lib。嵌入 C 核心，提供 kv、xv、time、duration、string 等标准库 opcode；二进制名仍是 kvlang。
runtime-rs byteseek 第二个 lib。用 kvlang 编写的 Agent Harness，运行在 runtime-rs 上，共享同一个 kvspace。

扩展通过注册生长，而不是改核心：新能力落在 /lib，任何 runtime 都可以提供。每个 lib 依赖同一行的 runtime 才能运行；lib 的 opcode 注册在该 runtime 的 /lib/<opcode> 下。
